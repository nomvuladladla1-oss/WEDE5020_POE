## Project Overview
Minelethu Baby Emporium is a South African baby retail brand under MGM Holdings.

The website is designed for new and expecting parents, guardians and customers looking for practical newborn essentials.

The website focuses on three main product categories:

- Essential Baby Wear
- Feeding and Nutrition Support
- Sanitary and Hygiene Essentials

The purpose of the website is to make it easier for customers to view baby essentials, find product information and send product enquiries.

---

## Brand Identity
Minelethu Baby Emporium is the customer-facing brand and MGM Holdings is the parent company.

MGM represents the family names Minenhle, Gugulethu and Mpumelelo.

The Minelethu name represents the family legacy behind the business.

## Website Goals
The website aims to:

- Create a professional online presence for Minelethu Baby Emporium.
- Provide clear information about the business and its products.
- Make baby products easy to find through organised product categories.
- Allow customers to make product enquiries.
- Provide a simple and user-friendly experience.
- Work correctly on computers, tablets and mobile phones.

## JavaScript Functionality
JavaScript is used to improve the user experience.
The website includes:

### Product Search
Customers can search for products by entering a product name.

### Product Filter
Products can be filtered according to:
- Essential Baby Wear
- Feeding and Nutrition Support
- Sanitary and Hygiene

### Enquiry Form Validation
The Enquiry form checks that the customer has entered the required information before the form is accepted.
The validation includes:
- Required fields
- Email address
- Phone number
- Product category
- Quantity
- Message
- Preferred contact method

### Contact Form Validation
The Contact form checks required information and displays a message when the form has been completed correctly.
This project currently demonstrates front-end form validation. The forms do not send information to a live database or email service.
